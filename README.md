# Attrition-Analysis-and-Prediction

This project involves predicting churn using statistical tests and machine learning techniques. Key steps include:

Performed feature importance analysis using Chi-Square, ANOVA, and Random Forest to identify significant predictors.

Applied SMOTE to handle class imbalance and improve model performance.

Trained a classification model achieving approximately 90% accuracy.

Exported the trained model as a .pkl file for integration.

Integrated the model with Power BI using Python scripting to enable real-time predictions via a custom dashboard.
